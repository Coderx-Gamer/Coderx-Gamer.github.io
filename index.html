UI-Utils

For Minecraft Java Edition

UI-Utils is a security research toolkit for Minecraft Java Edition. It gives your client the control needed to perform basic audits on how a server or plugin handles inventory and packet flow. This tool is only for the client-side half of a plugin pentest. Use it on servers you own or have permission to test.

Get it running

UI-Utils needs Fabric. Install all three, then start the game once with the Fabric profile.

STEP 01Fabric Loader

The mod loader itself. Run the installer, then pick the Fabric profile in the Minecraft launcher.

Download Fabric Loader →

STEP 02Fabric API

A required library. Put the downloaded .jar in your mods folder.

Download Fabric API →

STEP 03UI-Utils

The mod. Drop the .jar in the same mods folder and launch the game.
